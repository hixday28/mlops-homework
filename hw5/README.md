# ДЗ 5. Первый LoRA-ран

Вход — собственные train.pt (1267 примеров) и val.pt (111) из ДЗ 4.
Проверяется пайплайн обучения, переносимость и воспроизводимость адаптера.
Базовая модель Qwen3-0.6B, ревизия совпадает с ДЗ 4. Test не используется.

```bash
cd hw5
make install
make train
make compare
make check
```

Обучение двух вариантов занимает значительно больше времени, чем проверка.
Для первого пробного запуска:

```bash
uv run --locked python -m src.train --variant all_layers --max-steps 3 --val-limit 8 --out /tmp/hw5-smoke
```

Полный запуск использует `train.max_steps: null`, одну эпоху и весь train/val.
Варианты — адаптеры на слоях 0–27 и на слоях 14–27. База заморожена.
Батч 1, накопление 8 и gradient checkpointing выбраны для ноутбука с 16 ГБ RAM.
Лосс train усредняется по примерам микробатча, val — по обучаемым токенам;
их значения напрямую не сравниваются.

Результаты: [кривые](docs/curves.png), [пять вопросов до/после](docs/compare.md),
[разбор дефектов](docs/defects.md). Пять ответов не заменяют оценку качества.

Адаптеры, тензоры и JSON-метрики в Git не хранятся; они версионируются DVC.
Локальное хранилище — `dvc_remote_hw5` рядом с `mlops-homework`.
Если оно доступно: `uv run --locked dvc pull`. Для повторения на новом компьютере
нужно передать это хранилище или восстановить ДЗ 4, скопировать train.pt/val.pt
в data/tokenized/ и выполнить команды выше. Базовые веса отдельно скачиваются
с Hugging Face; офлайн-проверка требует их наличия в кеше.

Папка адаптера содержит LoRA-веса, конфигурацию, токенизатор с шаблоном и
run_config.json. Веса базы в неё не копируются.

## Видео

1. `uv run --locked dvc dag | cat`, затем `uv run --locked dvc status`.
2. `HF_HUB_OFFLINE=1 make check` (база уже должна быть в кеше): показать все девять зелёных проверок, финальную строку
   и отпечаток `06a02208c1f0`; скрипт выданной проверки не изменён.
3. Открыть docs/curves.png, docs/compare.md и docs/defects.md.
4. Показать params.yaml, src/train.py и dvc.yaml.

Повторять полное обучение во время записи не нужно: проверка сверяет
артефакты с текущим кодом и запускает два настоящих прогона по три шага.
