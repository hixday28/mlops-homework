# ДЗ 4. Токенизация и маска лосса

Вход: train (1267 примеров) и val (111) из собственного датасета ДЗ 3,
тег `hw3-v2`. Источник и лицензии описаны в [паспорте ДЗ 3](../hw3/docs/datasheet.md).
JSONL скопированы без изменений; test не используется. Веса модели не загружаются.
Токенизатор Qwen3-0.6B закреплён ревизией в params.yaml.

```bash
cd hw4
make install
make pull        # если доступно локальное DVC-хранилище
make repro
make check
```

Локальный DVC remote — `dvc_remote_hw4` рядом с папкой `mlops-homework`.
Он не доступен через GitHub: на другом компьютере нужно передать remote
или восстановить ДЗ 3 и скопировать его train/val:

```bash
mkdir -p data
cp ../hw3/data/train.jsonl ../hw3/data/val.jsonl data/
make repro
```

Для точного воспроизведения нужен выход именно `hw3-v2`; контрольные хэши входов
сохранены в inputs.dvc. При изменении версии ДЗ 3 это уже другой эксперимент.
Подробности восстановления исходного датасета — в README ДЗ 3.

Результат — data/tokenized/train.pt и val.pt с input_ids, attention_mask и labels.
Данные и .pt учитываются DVC и исключены из Git. Метрики и отчёт хранятся в Git:

- [Автоматический отчёт](docs/tokenize_report.md)
- [Метрики](metrics/tokenize.json)
- [Четыре дефекта и доказательства исправления](docs/defects.md)

Выбрано 2560 токенов при p99 train = 2326. Обрезано 5 train (0,39%) и 0 val;
ответ целиком не потерян ни у одного примера. Packing отключён.
Прогноз обучения — оценка по скорости генерации из ДЗ 1, реальное обучение не запускалось.

## Демонстрация

1. Выполнить `make check`, показать девять проверок, финальную зелёную строку
   и отпечаток `f2002c8c9519` (исходный tests/check.sh не менялся).
2. Открыть params.yaml: 2560, left, enable_thinking=false, порог 0.05.
3. Показать docs/tokenize_report.md: длины, обрезку, токены под лоссом, прогноз.
4. Открыть docs/defects.md, затем src/prompt.py, src/tokenize_data.py и src/collate.py:
   единый шаблон, границу маски, −100 и левый паддинг.
5. Показать dvc.yaml и выполнить `uv run --locked dvc status`.

Отчёт и метрики генерирует `make tokenize`; вручную их не редактировать.
