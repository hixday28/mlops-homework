# ДЗ 3 — датасет, DVC и проверка качества

Русскоязычные вопросы и принятые ответы по ML и инфраструктуре MLOps:
ML-фреймворки, Git, окружения, контейнеры и развёртывание.
Источник — тематический срез ru Stack Overflow; тексты не генерировались.

## Запуск

Из папки `hw3` внутри Git-репозитория, Python 3.12 и uv:

```bash
make install
make fetch        # первый раз: архив ~639 MiB, проверка SHA256 и тематический срез
make repro        # collect → clean → diversity → split → contamination
make check        # восемь проверок задания
make test         # регрессионные тесты
```

`make fetch` не нужен, если данные уже восстановлены через `uv run dvc pull`.
Remote локальный: `dvc_remote_hw3` рядом с папкой `mlops-homework`.
На другом компьютере этой папки нет — можно воспроизвести источник через `make fetch`.
Модели и GPU для ДЗ 3 не нужны.

## Версии

```bash
make v1
make v2
make diff         # dvc metrics diff hw3-v1 hw3-v2 --md
make push         # сохранить текущие артефакты в локальный remote
```

`make v1` и `make v2` меняют только `collect.version` в `params.yaml`.
Параметры, код, DVC-хэши и метрики хранятся в Git; `data/` и `.dvc/cache/` игнорируются.
`source.dvc` версионирует тематический снимок вместе с его манифестом.
`data/attribution.jsonl` связывает каждый пример с исходными авторами, URL и лицензиями.
При передаче данных нужно сохранять эту атрибуцию и лицензионные сведения из паспорта.
