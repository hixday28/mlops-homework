**Адаптер:**

> `git fetch` - это просто запрос на обновление. `git pull` - это обновление, включая обновление из `refs/heads/branch` в `refs/heads/branch` (если есть).

**База:**

> Модель может переобучаться, если она не учитывает новые данные или если данные не соответствуют требованиям модели. Это может происходить из-за следующих причин: /  / 1. **Неправильная выборка данных**: Если данные не соответствуют требованиям модели, она может переобучаться на данных, которые не используются в обучении. /  / 2. **Недостаточное количество данных**: Если модель обучалась на недостаточном количестве данных, она может переобучаться на новых данных, которые не были
