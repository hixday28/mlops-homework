# Паспорт датасета: вопросы по ML и инфраструктуре MLOps

Тема: вопросы и ответы по MLOps на русском. Практический срез охватывает ML-фреймворки, Git, окружения Python, контейнеры и развёртывание.
Согласование темы с преподавателем в доступной переписке пока не подтверждено.

## Источник и переработка

Источник — [IlyaGusev/ru_stackoverflow](https://huggingface.co/datasets/IlyaGusev/ru_stackoverflow), сборщик Илья Гусев; исходные авторы — участники [Stack Overflow на русском](https://ru.stackoverflow.com/).
Закреплённая ревизия: `3bfd79e598eaab49b8b5ec7397d5c12b0f22416a`. Архив содержит 437 604 вопроса с ответами и комментариями; снимок опубликован в 2023 году.
Архив скачан 22 сентября 2026 года. SHA256: `e3f6eda2b3df7de1d3cc4a45ce2e69bb1e439b7736cd8d81e911129bd512dab9`.

Переработка воспроизводится скриптами, ручная проверка не приписывается всему корпусу:
1. `fetch_source`: фильтр по списку технологических тегов и исключение посторонних прикладных областей. Общие вопросы только по NumPy/Pandas не включены.
2. `collect`: только один принятый ответ с оценкой ≥ 1; исключены зависимости от изображений, ответы короче 30 символов или с менее чем 20 русскими буквами. Статус принятого ответа сверяется с полями источника, но не доказывает техническую корректность.
3. Добавлены заголовок вопроса, поле topic и одна из четырёх системных инструкций, выбранная хешем ID. Текст ответа взят из источника, не сгенерирован.
4. Стабильная сортировка по SHA256 ID, максимум 100 примеров одного сочетания тегов. v1 — первые 1200, v2 — первые 1550 примеров в этом порядке.
5. Схема → длины → маскирование → точные повторы → near-dup.

## Сплит и контроль пересечений

Группа — нормализованный полный набор исходных тегов (`topic`). SHA256(seed + группа) относит целую группу к train/val/test. Seed = 42; интервалы хеша — 80/10/10. Реальные доли строк отличаются из-за неодинаковых размеров групп; при расширении старая группа сохраняет сплит.
Это не holdout всей технологии: Docker может встречаться в разных сочетаниях тегов. Сначала выполняется глобальная дедупликация вопросов. Отдельный завершающий гейт проверяет все пары сплитов.

| Версия | Train | Val | Test |
|---|---:|---:|---:|
| v1 | 994 (86.6%) | 84 (7.3%) | 70 (6.1%) |
| v2 | 1267 (85.5%) | 111 (7.5%) | 104 (7.0%) |

Во всех трёх парах: 0 общих ID, 0 нормализованных вопросов, 0 групп, 0 near-dup пар. Near-dup — точный Жаккар четырёхсловных шинглов ≥0.85, одинаковый при чистке и проверке. Используется инвертированный индекс с точной проверкой, без вероятностных пропусков LSH; параметр num_perm сохранён для совместимости интерфейса и не влияет на результат.

## Маскирование и ограничения

Маскируются email, телефоны, даты с маркером рождения, имена в путях /Users и /home, явно присвоенные строковые password/token/secret/api_key. Обрабатываются все три роли до дедупликации; учебные контакты тоже маскируются.
Счётчики текущей версии: `{"birth_date": 0, "credential": 12, "email": 153, "local_user": 195, "phone": 0}`. Это число совпадений регулярных выражений, а не подтверждённых персональных данных.
- Регулярные выражения не распознают все ФИО, адреса и секреты. Гарантия полной анонимности не заявляется; исходный архив и атрибуция локальные, в Git их нет.
- Это вопросы по отдельным компонентам MLOps, а не полный курс: заметен перекос к Git; MLflow и DVC почти не представлены в источнике.
- Ответы датируются периодом до снимка 2023 года; встречаются устаревшие подходы, например Docker Toolbox. Оценка сообщества не заменяет экспертизу и запуск кода.
- Семантические парафразы с разными словами могут иметь Жаккар ниже порога. Ноль здесь относится к измеренным критериям, а не ко всем возможным смысловым пересечениям.
- Отбор положительных принятых ответов и исключение картинок создают смещение. В тесте нет гарантии равномерного покрытия всех технологий.
- Для дальнейшего дообучения нужна содержательная оценка на актуальных задачах; этот набор прежде всего демонстрирует воспроизводимый учебный пайплайн.

## Версии и воспроизведение

`hw3-v1` и `hw3-v2` фиксируют параметры, метрики и DVC-хэши. Сравнение: `make diff` (`dvc metrics diff hw3-v1 hw3-v2 --md`).
Данные и атрибуция находятся в DVC; локальный remote — `dvc_remote_hw3` рядом с `mlops-homework`. При доступном remote: `uv run dvc pull`. На новом компьютере без remote: `make install`, `make fetch`, `make repro`. Источник закреплён ревизией и SHA256.
Исходный тематический снимок ~44 MiB хранится в DVC отдельно (`source.dvc`). Архив для повторного сбора ~639 MiB, поэтому первый `make fetch` требует времени и сети. В Git отсутствуют JSONL, архивы, веса моделей и файлы больше 5 MiB.
